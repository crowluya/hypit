# @hypit/breakdown

`hypit breakdown source.mp4 --to analysis --allow-paid [--analysis-provider kie|fal]`

Creates reference evidence and reports from local cuts, fal Scribe transcription and explicitly
selected KIE or fal video analysis. Produces JSON, ANALYSIS.md, TIMELINE.md, portable HTML,
clips, sampled frames and a contact sheet. Does not submit image/video/TTS generation.

Setup, recovery, constraints and model routes: `docs/zh/guide/kie-fal-breakdown.md`.
